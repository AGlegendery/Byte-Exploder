# Byte Exploder

**ساختهٔ [AGlegend](https://github.com/AGlegendery)** · [English README](README.md)

Byte Exploder هر فایل، پوشه یا متنی را به تصویری از پیکسل‌های درهم‌ریخته تبدیل می‌کند و با کلیدش دوباره برمی‌گرداند.

> این یک ابزار پنهان‌سازی است، نه رمزنگاری استاندارد و بررسی‌شده.

## قابلیت‌ها

- **فایل، پوشه یا متن ← تصویر PNG**؛ پوشه اول zip می‌شود.
- **بازگرداندن دقیق** همان بایت‌های اصلی (و باز کردن پوشه‌ها).
- **کلید داخل تصویر**: کلید در پیکسل‌ها پنهان می‌شود، نه در متادیتا. در این حالت هر کسی که برنامه را دارد می‌تواند تصویر را باز کند.
- **همهٔ خروجی‌ها مربعی** هستند.
- **حالت مقاوم**: فایل‌ها و متن‌های کوچک (تا حدود ۱۲ کیلوبایت بعد از فشرده‌سازی) طوری ذخیره می‌شوند که حتی اگر به‌صورت عکس فرستاده و فشرده شوند، خوانا بمانند.
- **سریع و کم‌مصرف**: رمزگذاری یک فایل ۳۰۰ مگابایتی حدود ۱٫۴ ثانیه.
- **رابط فارسی و انگلیسی** و یک **راهنمای تصویری** در اولین اجرا.

## ⚠️ مهم: همیشه Send as Document

تصویر رمزشده را در تلگرام یا هر پیام‌رسانی **به‌صورت فایل** بفرست (Send as Document، بدون فشرده‌سازی). اگر به‌صورت عکس فرستاده شود فشرده می‌شود و تصویرهای معمولی دیگر باز نمی‌شوند. فقط تصویرهای «حالت مقاوم» این را تحمل می‌کنند.

## نصب و اجرا

نیاز به Python 3.10 به بالا:

```bash
pip install -r requirements.txt
python app.py
```

در لینوکس (Debian/Ubuntu): `sudo apt install python3-gi gir1.2-webkit2-4.1`؛ اگر از virtualenv استفاده می‌کنی، آن را با `--system-site-packages` بساز.

## آزمون‌ها

```bash
pytest -q
```
